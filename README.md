# Artificial Intelligence in Web Accessibility for Visually Impaired Users

## Project Overview

This project focuses on developing an AI-powered web accessibility agent to assist visually impaired users in interacting with webpages.

The prototype uses Python and Playwright to inspect webpages, understand user requests, identify webpage elements and perform selected browser actions.

## Current Features

- Webpage reading and accessibility reporting.
- Identification of headings, buttons, links and form fields.
- Text-based questions and answers about webpage content.
- Product identification and filtering by colour, size and price.
- Form interaction and validation.
- Navigation between webpages.
- Spoken responses using text-to-speech.
- Confirmation before selected actions, such as adding products to a cart.

## Technologies Used

- Python
- Playwright
- HTML
- JavaScript
- pyttsx3
- Vosk (experimental voice input)

## Project Structure

The repository contains the Python development stages, HTML testing webpages and speech output module.

## Running the Prototype

1. Install Python.
2. Install the required Python packages.
3. Install the Playwright browser dependencies.
4. Run the integrated agent using:

   python stage38_continuous_agent.py

## Project Status

This is an ongoing academic prototype. Additional accessibility features and improvements will be added as development continues.
